# MyPet

화면 위를 돌아다니는 데스크톱 펫입니다. Windows / Mac 지원.

## 설치
Releases 페이지에서 내 컴퓨터에 맞는 파일을 받으세요.

### Mac
1. `mac-arm64.dmg` (M1/M2/M3 등 Apple 칩) 또는 `mac-x64.dmg` (인텔 맥)
2. 파일을 열어 MyPet을 Applications 폴더로 드래그
3. 처음 실행할 때 "확인되지 않은 개발자" 경고가 뜨면
   시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "그래도 열기" (한 번만)

### Windows
1. `win-x64.exe` 실행 (자동 설치)
2. "PC 보호" 창이 뜨면 "추가 정보 → 실행"

## 사용법
- 처음 실행하면 설정 창이 열려요. 이후에는 메뉴바(Mac) / 시스템 트레이(Windows, `^` 안에 숨어 있을 수 있어요)의 아이콘 → 설정
- 펫 좌클릭: 상태창 / 드래그: 이동 / 우클릭: 원형 메뉴(설정, 종료 포함)
- 설정 > 펫 추가: 기본 펫을 더 소환
- 설정 > 사진으로 펫 만들기: 동작별(기본/걷기/뛰기/신남/잠) 사진을 고르면 나만의 펫이 됩니다.
  한 동작에 사진을 여러 장 고르면 파일 이름 순서대로 움직임이 만들어져요.

## 개발자용
```
npm install
npm start
npm run dist
```
