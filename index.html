MyPet

바쁜 화면 위에서 나만의 귀여운 반려동물과 함께하세요.
가볍고 직관적인 인터페이스로 힐링을 선사합니다.

 macOS 다운로드 ⊞ Windows 다운로드 GitHub에서 보기
맥 기종 변경: Apple Silicon (M1/M2/M3) | Intel

💡 설치 방법 안내

macOS

  1. 다운로드한 .dmg 파일을 열고 MyPet 아이콘을 Applications(응용 프로그램) 폴더로 드래그합니다.
  2. 처음 실행 시 "확인되지 않은 개발자" 경고가 뜨면, 시스템 설정 ➡️ 개인정보 보호 및 보안에서 "그래도 열기"를 누릅니다.

Windows

  1. 다운로드한 .exe 설치 파일을 실행합니다.
  2. Windows "PC 보호" 창이 나타나면 [추가 정보]를 누른 뒤 [실행] 버튼을 클릭합니다.
